# 精简 Skill

## 指令

1. 阅读目标 `SKILL.md` 及必要的引用文件，识别必须保留的触发条件、判断规则、步骤、输出格式、授权边界和跨 Skill 接口。
2. 删除重复、空泛和通用教程；通用能力需要提示时只留关键词。
3. 将含糊表述改为明确的条件和动作；一句话能说清的规则不拆句。
4. 指令写清何时做、做什么、产出什么；解释单列，且只保留影响决策的内容。
5. 对照原文核对上述约束及必要的术语、字段、路径和顺序；无法确认的语义保留并标记。

## 输出

交付精简后的文件或文本，并简述关键删改与疑点。
