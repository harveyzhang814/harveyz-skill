## 平台专属能力的通用替代

| 目的 | 有原生能力时 | 无原生能力时 |
|---|---|---|
| 进出 worktree | 按 `manage-worktree` 的「按宿主进出」使用平台原生能力 | 按 `manage-worktree` 的「通用兜底」：Git 用 `git -C <worktree>`，文件读写用绝对路径 |
| 当前任务内委派 | 使用平台的 subagent 能力 | 当前 agent 串行完成 |
| 顶层任务 handoff | 使用能继承同一目录或 Git 状态的任务移交能力 | 写交接文档并停在可复现状态，请用户选择接手方式 |
| 等待接手方 | 使用平台的任务等待/消息能力 | 停止修改工作区，由用户协调接手与返回 |
<!-- @if agent_canvas -->
| 关闭画布节点 | 仅使用当前会话实际提供的 `close-node` | 不伪造关闭；报告状态并由用户处理 |
<!-- @endif -->

不要把某个平台的斜杠语法、设置文件、任务 API 或工作区切换命令当成跨平台标准。正文中的
skill 名称是跨平台约定；具体调用语法以当前运行环境为准。
